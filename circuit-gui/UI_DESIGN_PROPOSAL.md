# Circuit-GUI 界面设计优化方案

## 一、当前界面分析

### 1.1 现状概览

**器件栏 (DevicePalette)**
- 器件卡片尺寸：宽度自适应容器，高度约 `10rem` (160px)
- SVG图标容器：`h-10` (40px高度)
- 器件符号原始尺寸：60×40像素
- 卡片间距：3单位 (`space-y-3`)

**画布 (Canvas)**
- 器件符号尺寸：直接使用原始尺寸 `width=60, height=40`
- 网格：20×20像素的点阵网格
- 背景色：`#f0f0f0` 灰度点

**放置器件 (PlacedDevice)**
- 选中边框：2像素蓝色边框
- 选中边框内边距：5像素
- 标签位置：器件下方18像素
- 标签字号：12像素

### 1.2 发现的问题

1. **器件栏图标过小**
   - 40px高度的图标在160px高度的卡片中显得拥挤
   - 图标与文字标签之间的比例失衡
   - 无法清晰展示电路符号的细节

2. **画布器件尺寸偏小**
   - 60×40像素在现代高分辨率显示器上显得过小
   - 细节模糊，特别是在连接引脚处
   - 移动和选择时操作困难

3. **视觉层级不清晰**
   - 器件栏和画布之间缺少统一的视觉语言
   - 选中状态不够明显
   - 缺少专业的电路编辑器质感

## 二、行业最佳实践研究

### 2.1 ADS (Advanced Design System) 设计规范

**网格系统**
- 支持可配置的网格间距（单位：schem units 或 screen pixels）
- Pick Box（选择框）大小可调，默认10像素
- 吸附功能确保器件对齐

**器件面板设计**
- 分类清晰的器件库面板
- 支持缩略图和详细视图切换
- 拖拽放置时显示预览

**画布设计**
- 支持多种网格显示模式（点阵/线阵）
- 引脚和节点高亮显示
- 支持缩放和平移

### 2.2 Altium Designer 设计规范

**符号尺寸**
- 默认符号尺寸：10 DXP Default Units (100mil)
- 支持 Small 和 Smallest 两种线宽规格
- 符号可按需放大或缩小

**视觉一致性**
- 统一的IEEE/国际符号标准
- 引脚长度和间距标准化
- 颜色方案可自定义

### 2.3 通用图标设计原则

**尺寸规范** (基于业界标准)
- 小尺寸图标：12×12, 16×16, 24×24, 32×32, 48×48 px
- 中尺寸图标：64×64, 96×96, 128×128 px
- 图标应遵循2的幂次方递增原则

**线宽统一**
- 标准线宽：2px（24px网格基准）
- 所有线条宽度保持一致
- 角落圆角统一风格

**视觉平衡**
- 圆形元素需要比方形元素略大以达到视觉平衡
- 对角线条略粗以补偿视觉误差
- 保持整体的视觉重心一致

## 三、优化设计方案

### 3.1 器件栏优化

**推荐尺寸规格**

| 元素 | 当前值 | 推荐值 | 调整说明 |
|------|--------|--------|----------|
| 卡片高度 | 160px | 100px | 精简布局 |
| SVG容器高度 | 40px | 48px | 增大图标可见区域 |
| 卡片内边距 | 12px | 16px | 增加呼吸空间 |
| 图标缩放比例 | 100% | 120% | 提升图标清晰度 |

**视觉改进**
- 卡片背景：`bg-white` 保持简洁
- 悬停效果：边框颜色变化 + 轻微阴影
- 图标区域添加浅色背景区分：`bg-gray-50`
- 标签文字采用中粗字重：`font-medium`

**具体实现建议**
```
器件栏卡片设计：
┌─────────────────────────┐
│  ┌─────────────────┐    │
│  │                 │    │  ← 48px 高度容器，浅灰背景
│  │   [SVG 图标]    │    │
│  │                 │    │
│  └─────────────────┘    │
│                         │
│      电阻               │  ← 主标签，中粗字体
│        R               │  ← 前缀标签，小字灰色
└─────────────────────────┘
```

### 3.2 画布器件尺寸优化

**推荐尺寸规格**

| 器件类型 | 当前尺寸 (px) | 推荐尺寸 (px) | 缩放比例 |
|----------|--------------|--------------|----------|
| 电阻 | 60×40 | 90×60 | 1.5× |
| 电容 | 60×40 | 90×60 | 1.5× |
| 电感 | 60×40 | 90×60 | 1.5× |

**Canvas 渲染优化**
- 器件符号按比例放大1.5倍
- 引脚连接点保持清晰可见
- 添加微妙的阴影效果提升层次感

**选中状态优化**
```
当前实现：
stroke="#3b82f6" strokeWidth={2}

优化方案：
- 边框颜色：#2563eb (蓝色500)
- 边框宽度：2px
- 背景填充：rgba(59, 130, 246, 0.1) (淡蓝色透明)
- 圆角：rx=4
- 添加 1px 的虚线外边框表示可拖拽
```

### 3.3 网格系统优化

**当前实现**
```css
backgroundSize: '20px 20px'
backgroundImage: linear-gradient(...)
```

**优化方案**

**方案A：专业点阵网格**
```
网格间距：10px（画布单位）
点大小：1px
点颜色：#e0e0e0 (浅灰)
背景色：#ffffff (白色)
```

**方案B：线阵网格（推荐）**
```
网格间距：20px（画布单位）
线宽：1px
线颜色：#f0f0f0 (浅灰)
背景色：#ffffff (白色)
支持多级网格（粗网格100px，细网格20px）
```

### 3.4 统一视觉语言

**颜色方案**
```
主色调：
```

**字体规范**
```

- 字号：14px (画布单位)

- 字号：10px (画布单位)

```

## 六、总结

基于对 ADS、Altium Designer 等专业电路编辑软件的研究，以及现代 UI 设计最佳实践，我们提出以下核心优化方向：

1. **器件栏**：增大图标显示区域，改进卡片布局，提升视觉层次
2. **画布器件**：适当放大尺寸，增强选中状态可见性
3. **网格系统**：采用专业线阵网格，提供更好的视觉引导
4. **统一视觉语言**：建立系统的颜色、字体、间距规范

这些优化将使 circuit-gui 更接近专业电路编辑软件的体验，同时保持简洁易用的界面设计。
